# Инструкция для менеджера: как обновлять график курсов

График на сайте берётся из Google Таблицы. Программист не нужен — изменения появляются на сайте не позже чем через 15 минут (на боевом хостинге) или после ежедневной пересборки (на GitHub Pages; можно запустить вручную: GitHub → Actions → «Deploy to GitHub Pages» → Run workflow).

## Лист `schedule` — одна строка = одна дата курса

| Колонка | Что писать |
|---|---|
| `id` | Уникальный код, например `2026-12-iosh-ast` |
| `course_slug` | Код курса из выпадающего списка (лист `courses`) |
| `start_date` / `end_date` | Даты в формате `ГГГГ-ММ-ДД` |
| `country` | Казахстан / Онлайн |
| `city` | Астана, Алматы, Атырау… или «Дистанционно» |
| `format` | Очный класс / Виртуальный класс / Дистанционно (Teams) |
| `language` | RU / KZ / EN |
| `status` | `open` — набор открыт, `few_seats` — мало мест, `planned` — планируется, `closed` — набор закрыт |
| `seats_left` | Сколько мест осталось (необязательно) |
| `note` | Примечание (необязательно) |
| `published` | `TRUE` — показать на сайте, `FALSE` — скрыть |

## Частые действия

- **Добавить дату:** новая строка, заполнить колонки, `published = TRUE`.
- **Сменить статус:** выбрать новое значение в колонке `status`.
- **Скрыть строку:** `published = FALSE` (удалять не нужно).
- Прошедшие даты исчезают с сайта автоматически.
- Строки с ошибками (нет даты, неизвестный курс) пропускаются, сайт из-за них не ломается.
